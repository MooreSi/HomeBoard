# HomeBoard testing rules

These are the testing requirements for this repository's Node.js application.

- [Testing protocol](40-testing.md): red/green workflow, isolation, persistence and fail-closed gates.
- [Test authoring and review](test-rules.md): fixtures, assertions, boundaries and review checklist.
- [Verification](verify-rules.md): required checks before a commit and accurate reporting.

[DEVELOPMENT.md](../../../DEVELOPMENT.md) describes the application commands and
release checks. Runtime data, account tokens, personal photos and source archives
must never enter Git or automated fixtures.
