# Designer panel tools validation · 10 October 2026

The panel-tools update passes 125 API/unit regressions locally and inside the production Docker image, with zero failures or skips. Syntax checks cover 70 JavaScript files. Installer shell syntax and Git whitespace checks pass. Docker was rebuilt from the final source, and a disposable smoke container verifies schema 5 settings/library persistence across two restarts, static assets, authentication gating and optional password removal. The container and its volume are removed afterward; the user's running instance is untouched.

Five application regressions cover portable crop/clock composition with strict bounds, legacy migration without source mutation, stable forward/backward ordering through tied layers, bounded crop handles, durable compact restoration and clock visibility, and saving a frontmost reusable block while rejecting invalid layers. Missing features were observed red before implementation. The frontmost-block test exposed the old 0–10 layer limit before it was expanded to 0–31.

The browser suite now has 22 scenarios across Chrome and WebKit. The six additional scenarios verify layer commands and durable ordering; direct heading hiding/restoration without removing content; compact restoration after reload while preserving later colours; actual clip-path trimming, crop-handle dragging and reset without changing geometry; date/time-item dragging, show/hide, seconds, durable state and restoration of the normal DOM layout; and keyboard resizing with a round analog clock in an independent slot. Existing assertions remain. Final targeted Chrome/WebKit runs pass the crop reset and date/time restoration checks after the final changes. A restoration fixture was corrected to return to the dashboard after checking its settings iframe; the assertions remain intact. The multi-navigation WebKit fixture also waits for pending requests to finish before navigation/teardown, avoiding access-control errors from closing an in-flight fixture server without filtering browser errors.

Visual review uses temporary, labelled demo records. The typography, date/time composition menu and clean preview were reviewed in the browser. Cropping retains content and layout footprint; crop and internal clock coordinates currently apply to both orientations. Landscape and portrait panel geometry remain independent. Date/time controls retain the global digital/analog/both and date-format settings; location means the configured timezone.

Physical iPad/Android gesture testing and new live provider/account connections have not been exercised. Automated browser engines and existing provider fixtures do not establish those device/integration checks. This validation applies to local source and its built image; these changes have not been pushed, published or deployed.
