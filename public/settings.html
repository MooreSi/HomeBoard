THE SIMPLE ROUTE

Outlook calendar link

Connect an Outlook.com or Microsoft 365 calendar without an app registration. In Outlook on the web, open Settings → Calendar → Shared calendars → Publish a calendar. Choose the details you want to share, publish, then copy the ICS link.

Anyone with this link can read the published details. HomeBoard stores it privately; you can revoke it in Outlook. Publishing may be disabled by your organisation.

Microsoft setup instructions

Register your own HomeBoard app in Microsoft Entra. For Outlook.com/Hotmail select Personal Microsoft accounts or Accounts in any organizational directory and personal Microsoft accounts under Supported account types. Select Personal Microsoft accounts here for an Outlook.com account. A single-tenant or work-only registration causes the “account does not exist in tenant” error; adding your personal account as a guest is not the fix. Under Authentication → Advanced settings enable public client flows. Add delegated Calendars.ReadBasic access. Organisation policies may require admin consent or a tenant ID.

Google setup instructions

Enable Google Calendar API in Google Cloud. Create a Web application OAuth client, configure the consent screen and add your account as a test user when required. Register the exact callback URL above. Localhost HTTP works on the host browser; remote sign-in needs a Google-approved HTTPS domain or a localhost SSH tunnel. Calendar access is read-only. Testing-mode refresh tokens may expire after seven days.

YOUR MOMENTS, ON ROTATION

Photos

Upload photos

Upload from your device’s photo picker. JPEG, PNG and WebP are resized and converted in your browser; export unsupported HEIC as JPEG.

Apple iCloud shared album

In Apple Photos open a Shared Album → sharing / people settings → turn on Public Website and copy its link. Paste that link here, choose Apple iCloud shared album or All connected photo sources above, then check the album. This uses the public album, without your Apple ID or password. Anyone with the link can see the shared photos. New photos are checked every five minutes.

Apple Shared Albums guide ↗

Apple Photos / folder connection

Export an album from Apple Photos as JPEG to this folder, or choose a downloaded Mac Photos library (.photoslibrary). A library uses its originals folder; cloud-only photos, edits, albums and HEIC need JPEG export. The app automatically discovers changes and never deletes folder originals. In Docker use /apple-photos and mount your Mac folder with the installer. In LXC, use a folder mounted into the container.

AT HOME, ON ANY SCREEN

Installation & network

Choose local Node, Docker, or an unprivileged Proxmox LXC. Each setup reports the address to open on your tablet.

Run locally

npm run setup -- local

Checks Node, installs dependencies, binds to the LAN and starts the server. Linux can install a boot service with --service.

Docker

npm run setup -- docker

Builds and starts a persistent container. Use --photos /absolute/folder for Apple Photos or another folder.

Proxmox LXC

bash scripts/install-lxc.sh

Run on the Proxmox host. Select container ID, downloaded template, storage and bridge. DHCP gives the container a LAN address.

Available addresses

Use a trusted home network. Router guest isolation or centrally managed firewall policies may need your administrator. Do not forward this port to the internet.
